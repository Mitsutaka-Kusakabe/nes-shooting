1. ステージエディタとは？

このエディタは、ファミコン用シューティングゲーム『MOJAxMOJA WARS』の全4面（月・火星・木星・地球付近）の 背景地形・敵出現パターン・味方支援機補給・中ボス・大ボス、および 実機ROM用動作パラメータ（敵弾速度、編隊出現頻度、ボス狂乱HP閾値など） をWeb上で自由にデザインし、 ファミコン実機やエミュレータで即座に遊べる .nes ROMファイルを書き出すことができる開発ツールです。

✨ 本エディタの主な機能:
  • タイムライン型マップ編集: ゲーム全体の進行（全64列 = 約2分34秒）をパノラマ状に俯瞰して編集可能
  • 実機速度完全同期 BGM プレビュー: 実機と全く同じ速度（1列 = 2.4秒）でカーソルが進行し、中ボス（COL 32）や大ボス（COL 59〜63）でボスBGMへ自動切替
  • 実機拡張パラメータ設定: 敵弾の速さやボスの近接突進タイミングをスライダー/プルダウンで微調整
  • ワンクリック ROM 書き出し: 編集内容が埋め込まれた mojaxmoja-wars-custom.nes をその場で生成・ダウンロード
  • URLハッシュ保存: 編集データがURLに自動保存されるため、URLをブックマーク・共有するだけで誰でも同じ配置を再現可能

📏 実機タイムラインの仕様

  • 1列（メタ行）＝ 18タイル行 ＝ 144px ＝ 144フレーム（約2.4秒）
  • 全64列 ＝ 9,216フレーム ＝ 約153.6秒（2分33.6秒）
  • ゲーム中、自機が縦スクロールを進むと、1列（2.4秒）ごとに新しい地形や敵編隊が画面上端から生成されます。

3. ステージマップの編集方法

🎨 地形ブラシの種類と特徴

画面上部のツールバーからブラシ（0〜5）を選び、キャンバス上の列をクリックまたはドラッグすると、その列の地形フィーチャーを変更できます:

ブラシ 地形名称 グラフィックとゲーム性への影響
0: 星空 🌌 宇宙空間 (星空のみ) 地形障害物がなく、広々と動き回れる星空エリア。偵察モジャが出現。
1: クレーター ⚪ 月面クレーター / 岩石 画面左右に丸いクレーター地形を配置（単発オブジェクト）。
2: 小惑星帯 🪨 浮遊小惑星帯 (岩礁) 左右両サイドから大きくせり出す岩礁地形。中央の飛行可能エリアが狭まります。
3: ガス雲 ☁ 木星ガス雲 / 星雲帯 幻想的なガス雲が左右にたなびくエリア。
4: 要塞壁 🏰 モジャ宇宙要塞壁 左右が強固な要塞壁で塞がれた狭小通路！敵編隊との激戦エリアに適しています。
5: 軌道リング 💫 軌道リング・防衛線 画面を横断する破線状のリング状防衛ライン。

👾 敵編隊の出現パターンの仕組み

実機 ROM では、各列の 地形フィーチャー番号（下位2ビット: feature & 3） が、 その列でスポーンする敵の飛行パターンと連動しています:

  • feature % 4 == 0: V字編隊降下（標準的な敵編隊）
  • feature % 4 == 1: サイン波スヌープ降下（波打ちながら接近）
  • feature % 4 == 2: 縦一列強襲（真っ直ぐ突撃）
  • feature % 4 == 3: 左右挟み撃ち強襲
キャンバス上の赤や黄色の四角いドットは、その列で出現する敵の目安位置を示しています。

4. 全4ステージの切り替え

ステージバーのボタンを押すと、エディタで編集するステージを即座に切り替えることができます:

ステージ テーマと配色
STAGE 1: 月 (MOON) 暗灰・シルバー・白星（ボス: 紫）。クレーター主体の宇宙ステーション近傍。
STAGE 2: 火星 (MARS) 濃赤・オレンジ・朱色星（ボス: 深紅）。火星重力圏と激しい小惑星帯。
STAGE 3: 木星 (JUPITER) 黄土・深緑・緑星（ボス: 蛍光緑）。巨大ガス惑星の大赤斑近傍。
STAGE 4: 地球付近 (EARTH) 深青・シアン・青白星（ボス: マゼンタ）。地球周回軌道の最終要塞。

5. 実機拡張パラメータの調整（難易度カスタマイズ）

画面中央の 拡張設定バー では、ROM内に埋め込まれるゲームバランス（難易度パラメータ）を各ステージごとに独立して調整できます:

パラメータ項目 選択肢とゲーム性への影響
3機編隊スポナー間隔 6f (超ラッシュ) 〜 16f (ゆったり)
敵編隊が画面外から出現する頻度です。値を小さくするほど敵が次から次へと絶え間なく押し寄せる激戦になります（標準: 12f）。
敵弾速度 1 px/f (通常・迎撃容易)
2 px/f (高速弾)
3 px/f (激速スナイプ弾)
敵雑魚機・中ボスが撃ってくる弾のスピードです。3 px/f にすると超高速で狙い撃たれるため難易度が跳ね上がります。
ボス狂乱近接突進 HP 20% / HP 25% / HP 33% / HP 40% 以下
大ボス（宿敵・紅蓮のMS）がプラズマブレードを抜刀し、自機に向かって超高速で近接斬撃を仕掛けてくる残りHPの閾値です。
ボス画面端待機・撤退 15f (0.25秒・即反撃) 〜 60f (1.0秒・じっくり)
ボスが画面端に後退したあと、次の攻撃へ移るまでのインターバル時間です。

6. BGM 同期プレビュー

「▶ BGM同期プレビュー」ボタンを押すと、BGMを鳴らしながら自機のスキャンラインが実機と同じ速度（2.4秒/列）で進行します。

  • 🎮 実機連動モード:
    • 通常道中（COL 00〜26、COL 33〜57）は道中曲（STAGE 1）を再生。
    • COL 32（中ボス戦） 到達で自動的にボスBGM（180 BPM）に切り替わり、約10秒の交戦カウントダウン後、自動で撃破して道中後半へ復帰。
    • COL 59（大ボス決戦） 到達で再び大迫力のボスBGMへ切り替わり、決戦プレビューへ突入。
  • キャンバスクリックによるシーク: キャンバス上の任意の列（例えば中ボスの COL 32 や大ボスの COL 59）をクリックすると、その地点へ自機位置とBGMが瞬時に同期シークします。

7. 保存・共有・ROM書き出し

💾 拡張設定入り .nes を書き出す（ROM生成）

  1. ステージバーの 「💾 拡張設定入り .nes を書き出す」 をクリックします。
  2. 編集した全4ステージのマップデータと拡張パラメータが直接埋め込まれた mojaxmoja-wars-custom.nes がダウンロードされます。
  3. FCEUX、Mesen、RetroArch 等のファミコンエミュレータにドラッグ＆ドロップするか、実機カセットに書き込むことで、あなたが作ったステージと難易度で今すぐ遊べます！

📤 ca65 ASM 出力（ソースコード化 ＆ オリジナルへの恒久適用）

「自分が作ったステージをプロジェクトの標準仕様として永久保存したい」「Gitで管理して正規のゲームROMとしてビルドしたい」という場合は、ヘッダーの 「📤 ca65 ASM 出力」 を使用します:

  1. 画面右上の 「📤 ca65 ASM 出力」 ボタンをクリックします。
  2. 専用ダイアログが開き、ca65アセンブラ完全互換形式（LVLMAP01 マジックヘッダ、全4ステージ×64列のマップ配列、拡張パラメータ）のアセンブリソースコードが自動生成されます。
  3. ダイアログ内のボタンから適用します:
    • 📋 クリップボードにコピー: コード全体をコピーして、プロジェクト内の assets/stages.s を開いて丸ごと上書き貼り付けします。
    • 💾 stages.s ファイル保存: stages.s を直接ダウンロードし、プロジェクトの assets/stages.s に上書き配置します。
  4. プロジェクトルートで ninja またはビルドコマンドを実行すると、新しくビルドされる famicon-shooting.nes の標準マップがあなたの作ったステージに永久適用されます！

🔗 URLをコピー（Web共有・バックアップ）

  • マップを編集すると、ブラウザの URL ハッシュ（#...）に全データが自動的に英数字としてエンコードされます。
  • 「🔗 URLをコピー」を押すと共有用URLがクリップボードにコピーされます。このURLをブックマークしたり友人に送るだけで、いつでも全く同じ配置を再現できます。

📂 base.nes を指定（手元ROMの読み込み）

  • 手元で新しくビルドした game.nes や別バージョンのROMをベースにしたい場合は、このボタンから直接 .nes を読み込んでマップを再抽出できます。

👾 キャラインポート（キャラクターエディタ連携）

  • ステージバーの 「👾 キャラインポート」 をクリックし、Webキャラクターエディタ（docs/character-editor/）から書き出した characters.json を選択します。
  • ステージ上の自機（KBX-026）、味方支援輸送機（COL 27, 58）、中ボス（COL 32）、大ボス（COL 59〜63）、敵偵察機が、あなたがデザインしたオリジナルスプライトのアニメーションでタイムライン上にリアルタイム描画されます！
