1. 概要・特徴

このエディタは、ファミコン用シューティングゲーム『MOJAxMOJA WARS』のゲーム内 BGM を Web ブラウザ上で直感的に作曲・試聴し、 実機 ROM 構築用のアセンブラコード（.s）およびプロジェクトファイル（.nesbgm.json）へ直接出力できるシーケンサーツールです。

✨ 本エディタの主な機能:
  • 実機準拠のサウンドエンジン: パルス波2ch（方形波デューティ比 12.5%, 25%, 50%, 75% 再現）、三角波1ch（ベースライン）、DMC音源（実機デルタ変調バッファ $C000 キック / $C3C0 スネア）
  • 全64音階対応（A1〜C7）: 低音ベースから超高音（ボス曲の F#6 や D6 等）までカバー
  • アンドゥ・リドゥ履歴管理（最大60件）: ご操作時も Ctrl+Z で即座に復元
  • 更新マーク（未保存インジケーター）: 保存状態から変更された小節やノートに自動で ● 未保存 が点灯し、元に戻すと自動消灯
  • ca65 アセンブラ双方向変換: 作曲したデータを即座に .byte 配列として出力・既存コードの逆読み込みが可能

3. 音符（ノート）の入力と編集

🖱️ マウスによる操作

操作 効果
左クリック（空きマス） そのステップ・音階に音符を配置し、同時にプレビュー音を鳴らします。
右クリック（音符上） 配置済みの音符を消去（休符化）します。
クリック＆右へドラッグ 音符の長さを伸ばします（タイ / ホールド）。次ステップ以降に連続してホールドブロックが配置されます。
左端の鍵盤をクリック その音階の音色を試聴できます。クリックしたまま上下にドラッグ（グリッサンド）して音階を確認できます。

🎹 PC キーボードによるリアルタイム試聴演奏

ピアノロールにフォーカスしている際、PC のキーボードを使って鍵盤楽器のようにリアルタイム試聴演奏が可能です（C3〜C5 付近）:

白鍵: Z (C3), X (D3), C (E3), V (F3), B (G3), N (A3), M (B3), Q (C4), W (D4), E (E4), R (F4), T (G4), Y (A4), U (B4), I (C5)
黒鍵: S (C#3), D (D#3), G (F#3), H (G#3), J (A#3), 2 (C#4), 3 (D#4), 5 (F#4), 6 (G#4), 7 (A#4)

🥁 ドラム（DMC）の打ち込み

左サイドバーで DMC タブを選択すると、下部に 16ステップのドラムシーケンサーが表示されます。
各ステップの Kick（キック） または Snare（スネア） ボタンをクリックするとオン/オフが切り替わり、実機 DPCM サンプル音でプレビューされます。

4. 小節構成・ループ・更新マーク

🎼 小節パターンとオーダースロットの仕組み

ファミコンの楽曲データは容量削減のため、「小節パターン（A1, A2, B1 など）」 を定義し、 それを 「小節オーダー」 に沿って再生する構造になっています。

  • パターンの作成・管理: 左サイドバーの「+ 新規」「複製」「改名」「削除」ボタンで行います。
  • オーダーへの追加: 画面上部の + 小節追加 ボタンを押すと、現在選択中のパターンがオーダー末尾に追加されます。
  • オーダーの並び替え・削除: スロット右上の ✕ でオーダーから除外できます（パターン定義自体は削除されません）。

🔁 ループ設定

  • コントロールバーの 「🔄 ループ指定」 ボタンを押すと、現在選択している小節が ループ開始地点（|:） に指定されます。
  • 楽曲がオーダーの末尾（:|）まで演奏されると、自動的に指定したループ開始小節へシームレスにジャンプして演奏が継続します。

🟠 更新マーク（未保存インジケーター）

保存時やプリセット読込時からの差分変更がある場合、直感的に分かるマークが表示されます:

  • 音階ブロック: 変更・追加された音符の右上に小さな オレンジ色のドット（●） が描画されます。
  • 小節オーダースロット: 変更が加わった小節スロットに ● が付き、下線がオレンジ色にハイライトされます（例: 3:A1 ●）。
  • ヘッダー表示: 現在の小節番号に * が付き（例: BAR 01* : STEP 01）、右横に ● [変更あり] が表示されます。
  • 自動消灯: Ctrl+Z で元の状態まで戻すか、「JSON 保存」「ca65 ASM 出力（.s 保存）」を実行すると自動的に消灯します。

6. 保存・エクスポート・実機 ROM 反映手順

💾 プロジェクトの保存と読み込み

  • JSON 保存: 💾 JSON 保存 をクリックすると、楽曲全体の構成情報（各パターンの音階配列、オーダー順、ループ位置、テンポ、デューティ比）が .nesbgm.json 形式でPCにダウンロードされます。
  • JSON 開く: 📂 JSON 開く から保存済みの .nesbgm.json を選ぶと、いつでも編集を再開できます。

📤 ca65 ASM 出力と ROM 反映フロー

  1. 右上の 📤 ca65 ASM 出力 ボタンを押します。
  2. モーダルウィンドウに、NES サウンドエンジン仕様に準拠した ca65 アセンブラソース（.byte 配列形式）が自動生成されます。
  3. 「💾 .s ファイル保存」 を押すと music_stage_1.s などのファイル名でダウンロードできます。
    または 「📋 コピー」 でクリップボードにコピーして直接エディタに貼り付けられます。
  4. プロジェクトのリポジトリ内の assets/music_stage.s または assets/music_boss.s をこの内容で更新し、ROM をビルドすることで、ファミコン実機やエミュレータ上で自作 BGM が完全再生されます！

📥 既存 ASM ファイルの読み込み

📥 ca65 ASM 読込 ボタンを押し、テキストエリアに既存の music_stage.s 等の .byte 配列データを貼り付けて「インポート実行」を押すと、エディタ上に音階・ドラムパターンが自動解析されて復元されます。
