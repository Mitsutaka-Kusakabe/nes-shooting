# MOJAxMOJA WARS (ファミコン向け縦スクロールシューティング)

ファミリーコンピュータ (NES) 向けの 1人プレイ専用縦スクロールシューティングゲームです。  
6502 アセンブラ (`cc65` / `ca65` + `ld65`) を用いてフルスクラッチで実装しています。

## ▶ プレイ方法 (Webエミュレータ)

**[cluade-famicom-emu (Web版)](https://mitsutaka-kusakabe.github.io/cluade-famicom-emu/)** を開き、画面左上の **「ROMを開く」** から `game.nes` (または `roms/v1.0.0-mojaxmoja-wars.nes`) を選択するとブラウザ上で直接プレイできます。

## ストーリー

地球が謎の地球外生命体 **「MOJAxMOJA」** の侵略を受けている。  
地球防衛軍は地球外の宇宙空間へ最新鋭コアブロック戦闘機 **「KBX-026 SAMURAI」** を送り出し、これを迎撃する。  
ステージ途中で駆けつける味方支援輸送機から「脚部パーツ」「胸部パーツ」を受け取ってドッキング合体し、各宙域を支配する巨大 MOJAxMOJA 要塞・母艦を撃破して地球を救え！

## 特徴・仕様

- **コアブロック 4形態ドッキング合体システム**
  - ステージの **1/3 地点** で味方支援輸送機が **「脚部パーツ（Bパーツ）」** を、**2/3 地点** で **「胸部パーツ（Aパーツ）」** を懸吊して前線へ届けてくれます。
  - パーツと合体すると重厚な金属合体音（「ガッ・シャン！！」）とともに機体形状と主兵装が段階的に進化します。
  - 第2・第2.5・第3形態のときに被弾すると、撃墜されずに装着パーツをパージして **初期形態（コアファイター）** へ緊急脱出します（初期形態での被弾で1機ミス）。

| 形態 | 名称・見た目 | 合体条件 | Aボタン主兵装 | HUD表示 |
| :---: | :--- | :--- | :--- | :---: |
| **初期形態** | **コアファイター** (`16×16`) | 出撃時 / 被弾パージ時 | **通常ミサイル**（前方単発・連射可） | `F1` |
| **第2形態** | **コアファイター＋脚部** (`16×24`) | 初期形態 ＋ **脚部パーツ** | **3WAY ミサイル**（前方＋左右斜め拡散・連射可） | `F2` |
| **第2.5形態** | **コアファイター＋胸部** (`16×24`) | 初期形態 ＋ **胸部パーツ**（脚部スルー時） | **2WAY ミサイル**（左右2連装直進・連射可） | `F2.5` |
| **第3形態** | **ガンダム（MS立ち絵）** (`24×24`) | **脚部パーツ ＋ 胸部パーツ**（フル合体） | **貫通ロングレーザー**（自機から画面上端まで2秒間照射・敵貫通 / 連射不可・クールタイム0.5秒） | `F3` |

- **Bボタン：プラズマショックウェーブ（クールタイム制・範囲攻撃）**
  - 発動すると自機周囲に電撃リングが広がり、**画面内の敵弾をすべて一掃** しつつ範囲内の敵機・ボスにダメージを与えます。
  - 約2秒（120フレーム）のクールタイム制で、画面右下のバッジ（`R`＝発射可能 / 暗転＝チャージ中）で状態を確認できます。
- **全4ステージ構成（1ステージ約3分）＆ ハイパーワープ演出**
  - 月面から地球軌道まで全4宙域を収録。各ステージ終点では固有デザインの巨大ボス（`48×32` ピクセル）が待ち受けます。
  - ボスを撃破すると背景の星々が超高速の光の筋へと変化する **ハイパーワープ演出** が発生し、次の惑星宙域へと進撃します。

| ステージ | 宙域 | 背景特徴 | 巨大BOSS機 (`48×32`) |
| :---: | :--- | :--- | :--- |
| **STAGE 1** | **月 (THE MOON)** | 月面クレーター地帯と前哨基地 | **LUNAR BIG-CORE（月面双砲塔戦艦）** |
| **STAGE 2** | **火星 (RED MARS)** | 赤き渓谷・岩礁帯と突撃編隊 | **MARS HEAVY CRUISER（火星重装双胴戦艦）** |
| **STAGE 3** | **木星 (JUPITER)** | 木星ガス星雲帯と円盤編隊 | **JUPITER UFO MOTHERSHIP（木星巨大円盤母艦）** |
| **STAGE 4** | **地球付近 (EARTH ORBIT)** | 地球軌道防衛ライン・最終決戦 | **EMPEROR DREADNOUGHT（超巨大要塞戦艦）** |

- **サウンド（BGM & SFX）**
  - APU 4チャンネル（矩形波×2、三角波、ノイズ）によるタイトル・ブリーフィング・道中・ボス戦・エンディング BGM を実装。
  - ミサイル発射、ロングレーザー照射、ドッキング金属合体音（「ガッ・シャン！！」）、プラズマ範囲攻撃、爆発音など多彩な効果音を搭載。

## 操作方法

| ボタン | タイトル画面 | プレイ中 | ゲームオーバー / エンディング画面 |
| :--- | :--- | :--- | :--- |
| **十字キー ↑ / ↓ / ← / →** | メニュー選択 / 開始ステージ変更 (`STAGE 1`〜`4`) | 自機の8方向移動 | ― |
| **A ボタン** | ゲーム開始 | 主兵装発射（ミサイル連射 / 第3形態は2秒照射貫通レーザー） | タイトルへ戻る |
| **B ボタン** | 開始ステージ変更 (`STAGE 1`〜`4`) | 範囲攻撃（プラズマショックウェーブ・クールタイム2秒） | ― |
| **START** | ゲーム開始 | ポーズ ON / OFF | タイトルへ戻る |
| **SELECT** | メニュー項目切り替え (`START` / `STAGE SELECT`) | ― | ― |

## 必要環境・ビルド方法

ビルドには [cc65](https://cc65.github.io/) ツールチェーン（`ca65` / `ld65`）、`python3`、および `make` を使用します（Windows 環境では WSL 上でのビルドに対応しています）。

```sh
# Ubuntu / WSL の場合
sudo apt install cc65 make python3
```

```sh
python3 tools/gen_chr.py   # CHR-ROM タイルデータ (assets/chr.s) を生成
make                       # game.nes を生成 (iNES 形式, Mapper 0 / NROM-256: PRG 32KB + CHR 8KB)
python3 tools/verify_game.py  # 6502 エミュレータによる全4面通し自動検証テスト
make clean                 # ビルド成果物を削除
```

生成された `game.nes` を任意の NES エミュレータ（[cluade-famicom-emu](https://mitsutaka-kusakabe.github.io/cluade-famicom-emu/), Mesen, FCEUX 等）で読み込んでプレイできます。

## ディレクトリ構成

```text
├── Makefile              # ca65 / ld65 ビルド定義
├── nes.cfg               # ld65 リンカ設定 (PRG 32KB + CHR 8KB)
├── game.nes              # ビルド済み最新 ROM イメージ
├── roms/                 # バージョン別 ROM アーカイブ (v1.0.0-mojaxmoja-wars.nes)
├── screenshot.png        # ゲームプレイ画面スクリーンショット
├── docs/
│   └── editor/           # Web ステージマップエディタ (index.html / editor.js / style.css)
├── src/
│   ├── main.s            # エントリ・リセット処理・メインループ・NMI ハンドラ
│   ├── header.s          # iNES ヘッダ (Mapper 0 / NROM-256, 水平ミラーリング)
│   ├── ppu.s             # PPU 初期化・ステージ別パレット管理
│   ├── controller.s      # コントローラ入力・エッジ検出・16bit LFSR 乱数
│   ├── scroll.s          # 縦スクロール制御・背景地形ストリーミング描画
│   ├── player.s          # 自機4形態制御・ミサイル/2秒貫通レーザー・B範囲攻撃
│   ├── enemy.s           # 敵編隊スポーン・味方支援輸送機・合体判定・当たり判定
│   ├── boss.s            # 全4ステージ固有巨大ボス AI・弾幕・撃破演出
│   ├── state.s           # タイトル・ブリーフィング・ワープ・エンディング・OAM スプライト描画
│   └── sound.s           # APU サウンドエンジン (BGM シーケンサ & ドッキング音等の SFX)
├── assets/
│   ├── chr.s             # CHR-ROM タイルパターンデータ (tools/gen_chr.py により生成)
│   ├── stages.s          # 全4ステージマップデータ (LVLMAP01 互換)
│   └── drums.s           # DPCM ドラムサンプルデータ
└── tools/
    ├── gen_chr.py        # スプライト・背景・フォント CHR-ROM 生成スクリプト
    ├── verify_game.py    # 6502/PPU 自動検証テストスイート
    ├── render_screens.py # PPU スクリーンショット出力スクリプト
    └── font.s            # ASCII フォント元データ
```
